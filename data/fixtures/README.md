# Synthetic dataset

`demo_prices.csv` is generated by `python -m scripts.generate_demo_data`.
All values are synthetic. Familiar tickers are labels, not historical stock prices.
The generator uses fixed random seeds, a shared synthetic factor and asset-specific synthetic noise.
Dates are weekdays, including days which a real exchange would treat as holidays.

The fixture covers 2018-01-01 through 2025-12-31 (2088 rows, six symbols).
No real market data, licensed dataset, credentials or user-owned file is redistributed.
