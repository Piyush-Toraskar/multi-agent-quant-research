LOCAL REST API

API reference

The interface and these docs require no CDN or internet. All requests below are relative to http://127.0.0.1:8000.

Submit research

POST /api/research
Content-Type: application/json

{
  "query": "Test momentum on AAPL and MSFT against SPY.",
  "symbols": ["AAPL", "MSFT"],
  "benchmark": "SPY",
  "start": "2021-01-01",
  "end": "2025-01-01",
  "provider": "demo",
  "strategy": "momentum"
}

202 response: {"id": "<run-id>", "status": "queued"}

Read and export

GET  /api/health
GET  /api/research?query=momentum&limit=20
GET  /api/research/{id}
GET  /api/research/{id}/events?after=0
GET  /api/research/{id}/report
GET  /api/research/{id}/export/json
GET  /api/research/{id}/export/curve
GET  /api/research/{id}/export/trades
GET  /api/research/{id}/export/snapshot
POST /api/research/{id}/replay

Run states: queued, running, completed, rejected, failed, interrupted. A rejected run has a report whose engineering checks failed. Replay fixes the strategy and reuses the original content-addressed price snapshot.

The OpenAPI JSON includes every request field, bound, enum and response schema. Error 422 means invalid input; 429 means the local queue is full; 409 means results are not ready; 404 means an unknown resource.

Security boundary

This is a local single-user research application, not a hosted multi-user service. Do not expose the port publicly. There is no authentication, broker connection, arbitrary code tool or unrestricted SQL endpoint. The queue is bounded and in-process; restart marks unfinished runs interrupted.
