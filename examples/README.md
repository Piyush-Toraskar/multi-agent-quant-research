# Measured synthetic example

These files were produced by the working application during validation. All prices and financial
results are synthetic demonstrations, not historical market performance.

- `research_request.json`: a minimal request to submit.
- `synthetic_report.md`: the generated report.
- `synthetic_run.json`: the API response, including daily backtest detail and telemetry.
- `synthetic_equity.csv`: the exported daily curve.
- `synthetic_trades.csv`: the exported trade ledger.

The run IDs and timings are incidental. Run the default demo to create a fresh entry in your own
database. Do not describe synthetic return figures as real strategy performance on your CV.
